# Запуск
1. @BotFather → /newbot → получите BOT_TOKEN.
2. Выложите папку webapp на любой HTTPS-хостинг (GitHub Pages, Cloudflare Pages, Netlify, Vercel) → получите WEBAPP_URL.
3. pip install -r requirements.txt
   BOT_TOKEN=... WEBAPP_URL=https://... python bot.py
4. Напишите боту /start → кнопка «Открыть плеер».
